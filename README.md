# VELORIS X1 — Time, Engineered.

A cinematic, scroll-driven product experience for a fictional luxury
mechanical watch. One persistent WebGL world, a fully procedural watch,
GSAP scroll choreography, an exploded movement, a live material lab and an
editorial 3D → 2D moment.

## Run

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

`?quality=high|medium|low` forces a rendering tier for testing.

## Docs

- `docs/ARCHITECTURE.md` — how the scene, state and choreography fit together
- `docs/ASSETS.md` — asset sources and licences, and how to drop in a real GLB
